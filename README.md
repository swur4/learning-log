# Learning Log

## Описание проекта

Learning Log — веб-приложение на Django для ведения личного журнала обучения.

Пользователи могут:
- Регистрироваться и входить в систему.
- Создавать собственные темы для изучения.
- Добавлять записи к темам.
- Редактировать существующие записи.
- Просматривать историю своего обучения.

Каждый пользователь имеет доступ только к собственным темам и записям.

## Используемые технологии

- Python 3.12
- Django 6.1
- SQLite
- Bootstrap 4
- HTML5, CSS

## Установка и запуск

1. Клонировать репозиторий:

   ```bash
   git clone ССЫЛКА_НА_РЕПОЗИТОРИЙ
   ```

2. Перейти в папку проекта:

   ```bash
   cd learning_log
   ```

3. Создать виртуальное окружение:

   ```bash
   python -m venv venv
   ```

4. Активировать виртуальное окружение.

   Windows:

   ```powershell
   venv\Scripts\activate
   ```

5. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

6. Выполнить миграции:

   ```bash
   python manage.py migrate
   ```

7. Запустить сервер:

   ```bash
   python manage.py runserver
   ```

8. Открыть приложение:

   http://127.0.0.1:8000/

## Проверка тестов

Для запуска автоматических тестов выполнить:

```bash
python manage.py test
```

## Структура проекта

- `learning_log/` — настройки проекта и главные URL.
- `learning_logs/` — основное приложение, модели, представления и шаблоны.
- `users/` — регистрация и авторизация пользователей.
- `requirements.txt` — зависимости проекта.
- `manage.py` — инструмент управления Django.
